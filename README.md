# <span id="top">📦 Amazon Global Superstore – Power BI Analytics Project</span>  
### *(Hands-On Learning Project – Demo Dataset)*

The purpose of this project is to **practice data modeling, visualization, DAX, and dashboard building**.  

> ⚠️ **Note:**  
> This is **not real Amazon data**.  
> This is **only a learning & practice project** built using sample data.

## <span id="about-project">🔍 About the Project</span>  

This Power BI project provides a **global-level performance overview** of a fictional Amazon dataset, focusing on:  

- Sales  
- Product Categories  
- Ship Modes  
- Regions  
- Cities  
- Markets  
- Top-performing items  

It helps in understanding **how global retail businesses analyze performance** using Power BI.

---

## <span id="purpose">🎯 Project Purpose (Learning)</span>  

This project is created **only for self-learning**, covering:  

- Power BI data cleaning  
- Data modeling  
- DAX calculations  
- Visualization design  
- Filters, interactions & drilldowns  

The goal is to understand how to build **enterprise-style BI dashboards**.
